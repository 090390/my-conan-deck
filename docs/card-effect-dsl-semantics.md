# Conan TCG 카드 효과 DSL 해석 기준

이 문서는 카드 문구를 DSL 초안으로 옮길 때 공통으로 적용하는 해석 기준입니다. 현재 검토 배치도 같은 기준을 `interpretationRules`와 `runtimeCapabilitiesAdded` 필드에 저장하며, 초안 생성기는 해당 정보를 모델 입력에 함께 전달합니다.

## 일반적인 대상과 조건

- **대상 소유자 생략:** 별도 수식어 없이 “캐릭터를 리무브한다”고 하면 상대 현장의 캐릭터를 대상으로 합니다. “패에서”, “손패에서”, “자신의 현장에서”처럼 위치가 명시되면 그 위치와 소유자를 따릅니다.
- **인연:** `【인연: X】`는 효과 발동 시 자신의 현장에 카드명에 X가 포함된 카드가 있어야 한다는 조건입니다. 복합 카드명도 X를 포함하면 조건을 충족합니다. 이는 카드 효과의 발동 조건이며, 효과가 찾거나 선택하는 카드명 목록과는 별개입니다.
- **다국어 카드명 비교:** 인연·검색 조건은 한국어 카드명, 일본어 카드명, 지원되는 로마자 표기를 서로 대응해 비교합니다. 비교 대상은 카드의 실제 이름 필드로 제한하며, 효과 문장이나 검색 대상 목록에 그 이름이 언급된 것만으로 인연을 충족한 것으로 보지 않습니다.
- **파일 수:** `【FILEn】`은 효과를 발동하는 플레이어 자신의 현재 파일 수가 n장 이상이라는 뜻입니다. DSL fact는 `player.file.count`를 사용합니다.
- **사건 진행 단계:** `【사건편】` 및 `【해결편】` 조건은 해당 플레이어의 현재 `case_phase`를 기준으로 판정합니다. DSL fact는 `player.case_phase`이며 값은 `incident` 또는 `solution`입니다.
- **선언·슬립:** `【선언】【슬립】` 능력은 자기 턴 중 합법적인 타이밍에 액티브 상태인 원본 카드를 슬립시켜 발동합니다. 서버는 진행 중인 선택/응답이 없을 때 본인 턴의 begin/file/main 단계에서 이를 허용합니다. AI는 보드 상황과 목표가 존재하는지 검토해 능력 사용 시점을 판단하고, 자기 턴 밖에서 발동하지 않습니다.
- **공개와 확인:** 공개 대상에 `opponent` 또는 `all`이 포함되는 `reveal_cards`는 실제 공개 카드 정보를 양쪽 화면에 표시하고 상대의 확인 완료를 기다립니다. `awaitAcknowledgement`가 `false`여도 공개 확인 절차를 건너뛰지 않습니다. 확인 전에는 효과의 다음 단계(예: 손패 이동)가 진행되지 않습니다.
- **청 이외의 사건 색:** 사건 색에 청 이외의 색이 하나라도 포함되면 해당 조건을 만족합니다. 순수 백/황과 같은 단색 사건뿐 아니라 청백/청녹 등의 혼색 사건도 포함합니다. DSL fact는 `player.event.has_non_blue_color`를 사용합니다.

## 초안 생성·승인 경계

- `draft_candidate`는 현재 DSL 구조로 표현한 검토 후보이지 승인 완료나 실전 검증 완료를 뜻하지 않습니다.
- `review_required`는 정확한 실행 정의를 만들기 전에 규칙 확인이나 추가 런타임 지원이 필요한 상태입니다.
- `unsupported_trigger`는 현재 트리거 체계로 정확한 발동 시점을 나타낼 수 없는 상태입니다.
- 이미 `reviewedByUser: true`로 표시된 후보와 `approvalStatus: approved`인 후보는 후속 OpenAI 초안 생성에서 보존하며, 모델이 같은 효과를 다시 생성해 중복시키지 않도록 합니다.
- 초안 생성 및 구조 검증은 `supabase/seed/card_effect_definitions.json`의 운영 카탈로그를 자동 변경하지 않습니다. 운영 카탈로그에 들어가려면 별도의 런타임 검증과 사람 승인이 필요합니다.

- `filter_cards`는 플레이어의 선택을 요구하지 않는 내부 필터 명령입니다. 카드 인스턴스·소유자·출처 영역 래퍼를 보존하므로 후속 `move_cards` 단계가 동일한 실제 카드를 올바른 영역으로 이동할 수 있습니다.

- **이벤트 사용 트리거**: 이벤트 카드가 기본 이벤트 행동으로 현장에 놓이면 `event.played`가 발생합니다. 이벤트 효과 실행은 선택/공개 확인을 완료한 뒤 이어지며, 효과가 끝난 이벤트는 기존 `finish_event` 행동으로 리무브 영역에 옮깁니다.

- **동적 필터 값**: `filter.value`가 `{ "fact": "player.file.count" }` 같은 fact 객체이면 현재 플레이어 상태에서 값을 읽어 필터 비교에 사용합니다.

- **탐정 VS 괴도 사건 특징**: 현재 지원하는 코난 VS 괴도 키드 사건 규칙 코드 `conan_vs_kid_1261`를 `player.event.has_detective_vs_kid_trait` fact로 판정합니다. 새 사건 규칙이 추가되면 해당 fact의 매핑도 확장해야 합니다.
